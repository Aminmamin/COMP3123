# COMP3123 Lab Test 1

## Question 1

Created a `lowerCaseWords` function that takes a mixed array, removes the non-string values, and changes the remaining words to lowercase.

To run it:

    node question1.js

## Question 2

Created two promises. One resolves with a success message and the other rejects with an error message after 500 milliseconds.

To run it:

    node question2.js

## Question 3

Created scripts to create and remove the `Logs` folder and its 10 log files.

To create the log files:

    node add.js

    node remove.js
